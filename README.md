# Пункт пропуска №25

Статическая визуальная HTML-игра-поздравление ко дню рождения.

**Подзаголовок:** Таможенная декларация на въезд в следующий год жизни

Игра создана для Никиты на 25-летие.

---

## Что такое эта игра

«Пункт пропуска №25» — одностраничная браузерная игра, оформленная как цифровой пограничный терминал между возрастами 24 и 25. Игрок проходит паспортный контроль, сортирует жизненный багаж, отвечает на логические испытания, заполняет декларацию будущего и получает официальное разрешение на въезд в новый возраст.

Тон: официально-саркастический, взрослый, без приторной сентиментальности.

---

## Структура файлов

```
CheckPoint25/
```

## Как открыть игру локально

Откройте файл `index.html` в любом современном браузере.

Никакой установки, сборки и интернет-соединения не требуется.

---

## Как опубликовать через GitHub Pages

1. Откройте **Settings** репозитория на GitHub.
2. В левом меню выберите **Pages**.
3. В разделе **Source** выберите **Deploy from a branch**.
4. В разделе **Branch** выберите `main`, папку `/ (root)`.
5. Нажмите **Save**.
6. Через несколько минут GitHub выдаст ссылку вида `https://<username>.github.io/<repo>/`.
7. Откройте эту ссылку — игра будет доступна публично.

## Настройка

### Изменить имя именинника

В файле `script.js`, в самом начале, найдите объект `CONFIG`:

```js
const CONFIG = {
  playerName: 'Никита',
  currentAge: 24,
  destinationAge: 25,
  ...
};
```

Замените `'Никита'` на нужное имя.

### Изменить тексты игры

Все тексты, вопросы, карточки и реакции хранятся в структурированных объектах и массивах в `script.js`:

- `IDENTITY_QUESTIONS` — вопросы паспортного контроля
- `BAGGAGE_ITEMS` — карточки досмотра багажа
- `LOGIC_TRIALS` — испытания красного коридора
- `DECLARATION_ITEMS` — позиции декларации будущего

Тексты финального документа находятся непосредственно в `index.html`, в разделе `#screen-finalPermit`.

### Заменить изображения на .webp

Каждый ключевой визуальный ассет подключается через отдельный `<img src="assets/images/...">` в `index.html`. Чтобы заменить SVG на художественное изображение в формате `.webp`:

1. Поместите новый файл в `assets/images/`.
2. В `index.html` найдите нужный тег `<img>` по `src` и замените путь.
3. Пример: `src="assets/images/terminal-entry.svg"` → `src="assets/images/terminal-entry.webp"`.

Логика игры не затрагивается.

## Технические детали

- Чистый HTML / CSS / JavaScript. Никакого npm, никаких сборщиков, никаких фреймворков.
- Нет внешних зависимостей, CDN, шрифтов или API.
- Игра полностью работает офлайн после загрузки страницы.
- Адаптивна начиная с ширины 360 px.
- Учитывает `prefers-reduced-motion`.
- Кнопки имеют минимальную высоту 48 px для удобства мобильного управления.
